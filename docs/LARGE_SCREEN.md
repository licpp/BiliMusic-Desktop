# Android 大屏版

车机与 TV 共用独立 APK，应用 ID 为 `app.bilimusic.large`；手机版使用原应用 ID。代码在主分支维护。

## 已接入

- 首页续播、歌单 / 收藏 / 关注、列表查找、B站搜索、UP主视频与合集、合集及分P浏览。
- Android 原生音频、队列、音质、倍速、定时暂停、续播策略、逐字歌词和AI字幕。
- 视频在歌词旁的小窗播放，点击或遥控器选中半透明全屏按钮进入全屏；声音、画面与弹幕复用现有播放器时钟。弹幕支持开关、字号、透明度与密度。全屏控件空闲后自动隐藏，首次按键只唤出控件。
- 歌词页支持搜索与选择歌词版本、原文 / 音译 / 翻译切换；匹配结果显示语言标签，复用共用时间轴与保存流程。
- B站扫码登录、坚果云V2与冲突处理、听歌记录汇总、离线下载 / 播放 / 删除、播放缓存。下载前独立选择音质与格式，Android 10+ 默认导出到 `Download/BiliMusic`，也可选择系统文件夹。
- 触控、方向键、确认和返回；进度调整支持确认与取消。返回恢复列表位置、焦点、筛选条件、分类及设置展开状态；等待异步内容后再定位，用户主动操作会取消等待。
- 系统键盘使用可见视口布局，收起底栏并在表单内部滚动；确认进入编辑，返回先收起键盘，完成输入后保留可用操作焦点。
- 明暗主题（设备支持时可选「跟随系统」）、界面大小、歌词字号、播放页亮屏选项。
- 歌词页隐藏导航栏，封面与视频共用固定高度区域，切换不移动歌词和播放操作；宽封面完整显示。主页以内容为主，保留必要的歌单 / 合集名称，省去装饰性大标题。
- 左侧菜单末项向下直达底部歌曲卡片，跨区域按最近屏幕位置选焦点；歌词偏移保存时保留按钮焦点，支持连续操作。
- 播放页底部按封面 / 歌词两列分别对齐操作，无分隔线；匹配与偏移带图标。当前歌词居中，支持手指滑动、滚轮浏览和遥控器逐句导航，停手后恢复跟随；逐行 / 逐字高亮共用主题色。视频外框按实际画面比例适配。

- 同步后按可见条目补齐合集与 UP 主资料；方形专辑和宽封面按比例显示，文件夹 / 关联类型以纯白透明底角标区分。

复杂导入、评论、悬浮歌词、资料编辑与拖动整理没有大屏入口；同步协议与数据库仍完整复用。

## 开发与构建

```sh
npm run dev:large-screen
npm run build:large-screen
npm run android:large-screen
```

本地 Android 环境使用 `scripts/android-local.mjs`。大屏构建会复制当前工作区源码到忽略目录 `artifacts/build/large-screen/source`，使用单独 Cargo 缓存与生成工程，不改手机版的生成目录。前端输出为 `dist-large-screen`，安装包输出到 `artifacts/BiliMusic-版本号-Android-LargeScreen`。`-- --debug` 可构建调试包；正式构建产生未签名APK，签名后安装。

公共服务、播放器、同步和原生桥有改动时，分别验证 `npm run build` 与 `npm run build:large-screen`。大屏视图在 `src/large-screen`；公共主题继续来自 `src/styles/global.css`、`theme.css`。Android平台身份和大屏布局身份独立，不能让大屏误用桌面音频。

## 验证

`tests/large-screen.test.mjs` 覆盖方向导航、返回焦点的异步恢复 / 删除回退 / 操作取消、设置展开状态及两种安装包的 Manifest 处理。浏览器验收数据与截图放在忽略的 `artifacts/large-screen-qa`，不会进入应用。触控 / 遥控器的实机操作、蓝牙与车机后台运行仍需设备验收。

音乐卡片在首页、音乐库、搜索与 UP 主页面共用封面尺寸和间距，名称按封面居中；宽封面按实际比例显示。滚动弹幕按顶部空闲轨道分配，检查相邻弹幕追尾，保留 B 站指定的置顶 / 置底类型。
