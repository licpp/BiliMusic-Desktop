# 合集与分 P 的隐藏偏好

## 范围与身份

隐藏独立于收藏、歌单成员、历史和公开来源缓存。`season:<mid>:<seasonId>` 中的 BV 规则只影响该合集（包含其分类）；`video:<BV>` 中的 `cid:<CID>` 规则影响这个视频的分 P 展开和容器播放。单独保存或明确加入队列的曲目仍可播放。

恢复写入明确的 `false`，不删除规则。隐藏全部现有 CID 后，新增加的分 P 默认可见；直接隐藏 BV 则继续隐藏这个 BV 的新分 P。原始页码、CID、曲目 ID、来源标题和总分 P 数量均不改变。

列表投影保留来源，只有已知完整展开时才折叠为唯一可见的分 P；未知分 P 继续延迟解析。隐藏入口仅用于已收藏的 BV／合集、已关联收藏夹内的视频，以及已关注 UP 主的内容；收藏合集内展开的分 P 继承该范围。范围判断共用 `canManageVisibility`，读取当前账号的本地收藏查询，不额外请求 B 站。属于管理范围的列表始终保留恢复入口，可恢复单项或全部内容。界面共用主题工具栏、更多菜单及多选操作；大屏的更多菜单同样可操作。

普通未收藏、未关注的搜索结果完整显示和播放。取消收藏或关注不删除隐藏规则；重新收藏或关注后仍可管理恢复。未受管理的列表使用 `visibilityManaged: false` 和明确的空来源写入本地播放队列，避免旧规则在起播、延迟扩展所属合集或重启时重新过滤内容；该标记不进入云端同步协议。

## 播放

队列分别保存来源基底、可播放投影和每项来源。隐藏更新只重算投影，不擦除基底，也不暂停已经播放的声音。恢复可重新纳入原始内容；明确移出队列的项不会因此复活。正在播放的条目被隐藏时，按原始位置寻找下一项；顺序播放到末尾停止，手动切歌和列表循环保留环绕。单曲循环也要有可播放候选。本地快照只额外保存隐藏条目的元数据和原始 ID 顺序，不重复保存整份队列。

容器起播和切歌都检查规则。原生后台解析在获得分 P 和播放地址后再次读取数据库；全部隐藏使用独立的 `skip` 结果，播放器逐项移除候选，最多跳过队列中现有的项，不把它当成网络错误重试。Android、iOS、鸿蒙的原生队列保留分 P 继承的来源及明确加入的来源。

合集续播先选回原始条目；已隐藏则按原始顺序选下一个可见条目，必要时回到第一个。改选曲目从零开始，绝不套用原条目的时间；同一条目的进度仍由断点续播设置决定。

## 同步扩展

不向旧版严格校验的 Library、Progress 或 Statistics 协议添加字段。独立扩展 `visibility-v1` 使用现有 WebDAV 客户端、请求预算、调度和一次同步中的目录列表缓存。

- 每个键使用因果布尔寄存器；有因果先后时保留后来的操作，并发隐藏／恢复时隐藏优先。观察到并发结果后的恢复覆盖两者，无人工选择。
- 本地每批操作递增一个意图版本；每个同步目标分别确认版本。接收和投影云端规则不递增本地意图，不产生上传回声。
- 每批提交一个 gzip 快照，只包含隐藏偏好，不包含视频目录。快照由哈希寻址，提交标记位于既有 actor 的控制目录，文件名为 `ext-visibility-v1-<generation>-<hash>.head`。旧版的数字前缀 `.json` 发现逻辑忽略它。
- 快照独立可读，不依赖此前的增量链。待提交字节在本地事务中冻结；上传或确认中断后重试相同字节，再提交更新的本地意图。
- UID、vault、seed、命名空间、actor、代次、摘要及因果寄存器逐项校验。数据库写入同时检查账号会话和当前连接；本地操作也使用会话令牌。独立写入身份使用 SQLite 之外的序号预留，数据库回滚后换身份。
- 扩展失败保留本地状态和待提交内容，单独显示在云同步设置中，不阻断已完成的核心音乐库同步。共享限流仍然约束所有请求。

当前保留扩展的不可变对象和提交标记。长期大量编辑会增加控制目录长度；尚不做远端垃圾回收。以后若优化保留策略，需要另行设计并测试离线读取和回滚边界。

## 验证

`tests/fixtures/content-visibility.json` 同时由 TypeScript 与 Rust 原生解析测试使用。测试覆盖唯一可见分 P、隐藏第一分 P、未知展开、新分 P、明确加入队列、恢复基底、全隐藏终止、隐藏续播改选和异步起播竞态。

Rust 测试使用本机 WebDAV 模拟服务器，验证首次发布、恢复传播、无上传回声、复用目录发现、原批次重试、写入身份回滚以及并发隐藏／恢复合并，并运行多副本随机离线编辑与重复、乱序传输。`tests/fixtures/queue-visibility-order.json` 在 TypeScript、Android、Swift 和鸿蒙之间验证隐藏当前条目后的方向与终止规则。原生队列还检查延迟展开和旧 WebView 队列镜像不会丢失播放来源。
