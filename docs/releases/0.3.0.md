# BiliMusic 0.3.0 · 大版本更新

这是自 0.2.8 以来的一次大版本更新，集中升级歌单导入、跨端听歌统计、歌词与播放体验。安装包为 macOS Apple Silicon、Windows x64、Android ARM64 与需自行签名的 iOS ARM64 IPA。

## 新功能

- 从网易云、QQ 音乐、文本列表导入歌单，自动匹配 B 站视频与分 P；并发匹配、暂停续导、结束导入及按曲懒加载重新匹配。B 站收藏夹默认关联，可选择复制。
- 歌曲资料与歌词支持网易云和 QQ；提供来源筛选、翻译和音译切换、歌词定位播放，优化带序号标题的匹配。
- 分段播放缓存默认 512 MB，可修改容量或清理；优先复用缓存，离线播放已缓存覆盖的片段，不预先下载整个长视频。
- 搜索使用 B 站联想，支持键盘选择、收起及输入法处理。
- 听歌统计支持周、月、年、累计、歌曲排行与热力日历。通过所选服务自动汇总同一 B 站账号各设备时长，按来源和月份压缩传输，保留完整月累计及近 90 天逐日歌曲明细。旧时长一次迁移，次数从新版起记。
- UP 主分组、备注与从 B 站关注批量导入；关注标题旁提供新建文件夹与导入入口，收起时隐藏；关注文件夹与收藏文件夹独立，并使用相同的目录式列表，文件夹优先、同类最近新增在前。侧栏箭头位置固定，导入面板滚动自动加载并使用紧凑搜索框。备注目前保存在本设备。
- macOS、Windows 提供置顶迷你播放器、内部队列与滚动歌词，接入系统媒体键和快捷键。

- 合集详情统一为一个搜索入口；UP 主详情可在当前 UP 主全部投稿中搜索，搜索分页及播放队列后续加载沿用关键词。

## 播放与布局优化

- 更新代理首段复用、媒体 Range 校验与备用线路续传，补齐播放无进展恢复。
- iOS 播放恢复检查本机代理监听，避免后台长期暂停后的失效监听被反复复用；播放解析与同步网络分离。
- Android 横屏弹幕使用实际布局尺寸重建画布，并响应方向、视口及像素密度变化。
- 四端统一歌单导入、资料与歌词匹配、统计、长标题、封面比例和弹窗层级；收紧移动端底栏与定时面板。
- 桌面优化封面尺寸、侧栏布局、窗口状态保存和窄窗口布局；空格在播放控件获得焦点后仍控制播放暂停。快捷键说明默认收起，窄窗口搜索卡片不再错误折行。

- 统一详情页搜索框与原搜索框样式，紧凑歌词搜索、粘贴歌词和平台筛选控件；PC 底部集中显示原文 / 音译 / 翻译、AI 字幕与评论，歌词播放图标与选中行横线对齐。

## 使用与升级

- 保留原应用标识、各账号数据库与 Android 固定发布签名，支持从同签名 0.2.8 覆盖更新。
- 音视频仍来自 B 站；国内音乐来源仅用于清单、资料及歌词，不引入大模型或付费 API。
- 缓存不等同于完整下载，离线只能播放已缓存的部分。缓存和设备偏好不上传云端。
- 当前同步请使用坚果云，客户端直接连接，同一 B 站账号的各端使用同一坚果云账号与目录。BiliMusic 云暂不可用，已在设置中置灰。
- 使用同步时，建议将参与同步的设备一并升级到 0.3.0，保证独立关注文件夹与听歌统计一致。
- 统计日期统一为 UTC+8。复制升级前的同一数据库不能在多台设备各自重复导入；降级旧客户端不会显示新版新增统计。
- iOS IPA 仍需自行签名；macOS 使用 ad-hoc 签名，Windows 暂无发布者签名。

四端共用 UI、匹配规则、缓存与统计模型；迷你窗口/桌面快捷键属于桌面能力，锁屏媒体控制分别使用系统原生播放器。构建与自动检查结果记录在发行目录，不能替代长期后台、耳机及特定手机的真机体验。
