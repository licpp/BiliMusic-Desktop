## 发版条件

- 前端构建与测试、Rust 格式检查与测试、云同步服务测试、官网清单测试通过。
- 四端安装包来自同一已提交源码；版本为 0.3.0，Android versionCode 为 30000。
- macOS 最终 DMG 挂载校验与签名验证；Windows GUI 子系统验证；Android 固定签名、版本与桥接保留验证；iOS 真机平台、ARM64、背景音频与桥接权限验证。
- 发行目录提供源码提交、各包 SHA-256、体积、许可证与更新说明。
- 安装包准备与官网激活分开，不能将旧包改名为新版本。
