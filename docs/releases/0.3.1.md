# BiliMusic 0.3.1

相对 0.3.0，集中升级播放、歌词、音质下载、歌单管理与多端交互。

## 播放与音质

- 优化音源选择、首段加载、断线续传和播放状态恢复，改善起播不稳定及进度反复跳动。
- 切换音质时继续播放原音源，新音源准备完成后接替；自动音质优先最高可用 AAC，Hi-Res 需手动选择。
- 识别可用的 Hi-Res / FLAC 音轨；下载音质独立于播放设置，可保存真正的 FLAC 或保留原始封装。
- 搜索、歌词等页面的更多菜单增加下载入口，移动端下载选择统一为底部面板。

## 歌词与桌面控制

- 支持逐字歌词，调整高亮与进度动画；返回前台立即对齐当前歌词，改善滚动和侧滑返回的手势冲突。
- 新增透明双行悬浮歌词，可调字号与配色；固定行位、长句随歌词时间滚动，并为首尾留出阅读时间。
- 锁定悬浮歌词后可点击穿透，桌面悬停显示解锁按钮；Android 使用小型半透明解锁按钮，控制栏自动收起。
- AI 字幕可用于悬浮歌词，句间等待时保持当前句高亮；iOS 在通知中心与锁屏播放卡片显示歌词，鸿蒙完善系统歌词显示。
- 桌面快捷键支持自定义单键、组合键和鼠标侧键。

## 歌单与同步

- 本地歌单与 B 站关联收藏夹统一在歌单中管理，以链接图标区分；收藏选择自动排除不兼容的整部视频或单独分 P。
- 歌单、已收藏和关联列表增加列表内搜索，收藏文件夹优先排列。
- 通过坚果云同步已导入的 B 站关联收藏夹清单，其他设备可恢复关联入口。

## 评论与界面

- 完善评论回复对象展示、默认表情与输入预览，修复 iOS 表情输入光标和键盘展开时的布局问题。
- 云同步、播放缓存和悬浮歌词设置统一为可展开的布局，优化预览、容量选择及浅色主题。
- 移动端导入 B 站关注改为底部面板，统一下载等面板交互；修复歌词居中、菜单层级和展开图标。
- 在搜索及详情等位置补充视频发布日期，封面增加分 P 或合集数量标记；改善听歌统计封面加载。

## 平台修复

- 修复 Android 通知栏上一曲、下一曲及耳机按键控制。
- 修复 macOS 悬浮歌词相关稳定性问题，以及主窗口无法从 Dock 或状态栏恢复的问题。
- 完善鸿蒙播放状态、通知与实况胶囊封面，以及坚果云上传兼容性。

## 安装包

macOS、Windows、Android、iOS 和鸿蒙 NEXT 五端更新。iOS 与鸿蒙包需自行签名安装；macOS 为 Apple Silicon 安装包。
