# 播放与资料库体验优化

先交付 macOS / iOS；共享逻辑同时用于其他平台，不单独复制。

## 第一阶段 · 0.2.4 本地体验包

- 记住封面 / 视频偏好，切歌、重新打开歌词页、重启后保持。视频不可用时临时回退封面，不改偏好；封面模式不主动解析视频。
- Mac 封面和视频共用固定媒体区域，标题位置不随切换移动。
- 歌词调整保留原来的紧凑竖排样式，偏移立即预览，保存合并且串行执行；支持提前 / 延后 0.5 秒、长按、点句对齐、重置、保存失败重试。
- 歌词视口使用内容占位，不再通过大块 padding 扩大视口，避免尺寸变化后滚动和居中失准。
- 桌面收藏条目取消常驻拖动手柄，封面 / 标题与文件夹对齐，可直接拖动条目到自建文件夹。
- 新加入的歌曲 / 分 P 置顶，批量加入保持批内顺序，不移动重复歌曲。复制 B 站收藏夹时保留导入顺序。
- 我喜欢固定顶部，其他歌单按创建顺序倒序，编辑不改变顺序。同步保留本机已有歌单和文件夹的创建顺序；同步协议尚不传递创建时间，新设备收到多份旧歌单时暂不保证与原设备完全一致。
- 视频浮层可直接关闭弹幕，状态持久化，关闭时停止渲染、不为后续歌曲请求弹幕。

简单验证：39 项前端检查、41 项本地 Rust 测试通过；外部服务专项测试沿用忽略。浏览器用演示歌词检查提前 / 延后的即时高亮及桌面标题位置。

建议体验：切歌后的观看模式、连续调节歌词、关闭重开后的偏移、新增单首与批量分 P 的顺序、拖动收藏到文件夹。

## 第二阶段 · 0.2.4 模拟器体验版

- 移动端歌词匹配、歌曲信息编辑改为独立子页面；歌曲信息匹配结果直接列在编辑页下方，点击回填并保留列表，支持切换来源；输入区域适配键盘。
- 从搜索打开分 P 时进入独立列表页，支持列表内搜索、多选、整行播放和长按菜单，每行收起常驻的红心 / 加入队列按钮。
- 分 P 共用列表使用双行信息布局，显示时长、当前歌曲状态。
- iOS 视频全屏请求系统横屏，退出恢复进入前方向；隐藏主导航与播放栏，在视频浮层提供进度、暂停 / 播放。
- 复用当前视频实例；iOS 15 或系统暂未完成旋转时使用横向视频布局。
- 横屏弹幕设置使用紧凑浮层，限高并可滚动；点击空白可关闭。
- 按要求仅做编译和模拟器安装，不进行操作测试。

## 第三阶段 · 0.2.4 模拟器体验版

- 支持真正的 B 站合集（多个 BV）：从所属合集入口查看，收藏到现有收藏夹，打开时读取最新列表，也可复制为独立本地歌单；关联列表保留 B 站顺序，以视频为最小单位。
- 歌词选择页增加 B 站字幕来源，支持平台提供的 AI 字幕、语言选择、逐句时间和既有偏移调节；正文与选择只保存在本机缓存，不上传云端。
- 现有播放设置内增加实际可用的音质 / 清晰度选项；偏好按设备保存，切换保留进度与暂停状态，视频切换不重新启动音频。
- 「我的 → 听歌统计」展示本周和累计时长、歌曲数、天数、周分布与常听榜；iOS 在原生 AVPlayer 计时，macOS 根据真实播放状态计时，拖动进度不累计。
- 统计从当前版本开始，本机按天汇总，保留近 90 天单曲日记录和累计计数，不把统计当成歌曲 metadata 的永久保留引用，不上传服务器。
- 自有云校验器已增加合集引用支持，现有同步协议字段和体积限制不变；新增合集的跨设备同步需使用本阶段及更新版本客户端。
- 按用户要求以编译、构建与安装为主，不做应用操作测试。
