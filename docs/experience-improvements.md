# 播放与资料库体验优化

先交付 macOS / iOS；共享逻辑同时用于其他平台，不单独复制。

## 第一阶段 · 0.2.4 本地体验包

- 记住封面 / 视频偏好，切歌、重新打开歌词页、重启后保持。视频不可用时临时回退封面，不改偏好；封面模式不主动解析视频。
- Mac 封面和视频共用固定媒体区域，标题位置不随切换移动。
- 歌词调整保留原来的紧凑竖排样式，偏移立即预览，保存合并且串行执行；支持提前 / 延后 0.5 秒、长按、点句对齐、重置、保存失败重试。
- 歌词视口使用内容占位，不再通过大块 padding 扩大视口，避免尺寸变化后滚动和居中失准。
- 桌面收藏条目取消常驻拖动手柄，封面 / 标题与文件夹对齐，可直接拖动条目到自建文件夹。
- 新加入的歌曲 / 分 P 置顶，批量加入保持批内顺序，不移动重复歌曲。复制 B 站收藏夹时保留导入顺序。
- 我喜欢固定顶部，其他歌单按创建顺序倒序，编辑不改变顺序。同步保留本机已有歌单和文件夹的创建顺序；同步协议尚不传递创建时间，新设备收到多份旧歌单时暂不保证与原设备完全一致。
- 视频浮层可直接关闭弹幕，状态持久化，关闭时停止渲染、不为后续歌曲请求弹幕。

简单验证：39 项前端检查、41 项本地 Rust 测试通过；外部服务专项测试沿用忽略。浏览器用演示歌词检查提前 / 延后的即时高亮及桌面标题位置。

建议体验：切歌后的观看模式、连续调节歌词、关闭重开后的偏移、新增单首与批量分 P 的顺序、拖动收藏到文件夹。
