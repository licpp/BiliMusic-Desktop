# 桌面迷你播放器

- 入口位于主界面和歌词页右上角的画中画图标，只在桌面应用显示；开发浏览器提供布局预览。
- 复用当前主窗口、音频对象和播放队列，不创建第二个播放器，也不重新解析播放地址。主页面隐藏但不卸载，保留搜索状态；进入时关闭歌词视频，恢复时可返回原歌词页。
- 窗口默认 480×72 逻辑像素，允许横向调整至 400–720，收起时高度固定；无原生标题栏并置顶。拖动背景或歌曲信息移动窗口。
- 保留封面、歌曲信息、喜欢、上一首、播放/暂停、下一首、队列、歌词、音量及进度。队列在同一迷你窗口内展开（480×304），歌词在副标题行显示并随播放更新，长文本自动滚动；两者均不恢复主界面；左上角可隐藏播放器或恢复窗口，隐藏不停止播放。
- Native 保存进入前的尺寸、位置、窗口装饰和置顶等状态。单独的恢复快照覆盖进程退出时窗口状态插件保存的迷你尺寸，防止重启后主界面异常变小；成功恢复后删除快照。快照只存本机应用配置目录，不参与云同步。

## 必要验证（2026-11-11）

- macOS 原生 WebView 测试使用独立应用标识 `app.bilimusic.miniqa` 和隐藏测试窗口，不读取正式应用资料库。
- 正常 1000×700 → 迷你 480×72，原生 `always_on_top=true`、`decorated=false`；返回后物理尺寸、位置、窗口装饰与原置顶状态一致。
- 在迷你模式直接退出，再次启动后恢复 1000×700 正常窗口。
- ego-browser 验证 480×72 布局不溢出，音量面板位于窗口范围内；恢复后保留搜索条件并返回原歌词页，顶部按钮无文字及边框。
- 前端测试和构建、Rust 编译检查通过。Windows 使用同一组跨平台窗口 API，尚未进行 Windows 实机窗口验证。

本次更新：macOS 使用透明原生窗口与 16px 内容层圆角；收起/展开队列不创建第二个播放器。真实 Apple AVFoundation 播放探针确认音频 Range 不得截短，音频仍按 256 KB 分段缓存。
