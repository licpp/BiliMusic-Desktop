## Default Permission

Native audio and queue controls for the local iOS window

#### This default permission set includes the following:

- `allow-lyrics`
- `allow-play`
- `allow-control`
- `allow-snapshot`
- `allow-queue`
- `allow-register-listener`
- `allow-remove-listener`
