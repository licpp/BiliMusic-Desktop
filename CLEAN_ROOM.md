# Clean-room development policy

Resonance is a new implementation created in a new source tree. It is not a fork of BiliMusic and does not import code, styles, assets, icons, copy, package metadata, build scripts, or Git history from that repository.

## Allowed inputs

- Product requirements written in plain language.
- Behavior observed while using publicly available software.
- Public platform documentation and independently recorded API contracts.
- Dependencies whose licenses permit use and redistribution.

## Disallowed inputs

- Copying or mechanically translating source code from the reference application.
- Reusing its name, icon, screenshots, visual assets, README text, or distinctive page composition.
- Applying a new license to third-party code that was not licensed for reuse.

Every contributor must disclose copied third-party material and its license before submitting it. New dependencies must be recorded in the third-party notice generated for each release.
